## Intended Use

**Primary intended use:** An assistant for software developers answering
questions about programming languages, tools, libraries, and system design.

**Appropriate uses:**
- Explaining programming concepts.
- Debugging code snippets.
- Answering technical questions with code examples.

**Out-of-scope uses:**
- Medical, legal, or financial advice.
- Content requiring world knowledge past the base model's training cutoff.
- Safety-critical systems.
- Production use without additional evaluation and safeguards.

---

## Training Data

### SFT stage

17,902 instruction-following examples, sourced from:
- `yahma/alpaca-cleaned` (filtered to technical domain).
- `databricks/databricks-dolly-15k` (closed_qa, information_extraction, general_qa).

Domain filter applied: keyword recall + embedding precision (F1 0.86 vs
200 hand labels). MinHash deduplication at Jaccard 0.85. N-gram decontamination
against all evaluation prompts.

### DPO stage

8,231 preference pairs from:
- `HuggingFaceH4/ultrafeedback_binarized` (primary source).
- `Anthropic/hh-rlhf` (helpful split).

**Known data limitations:**
- Domain filter is imperfect (F1 0.86 leaves ~14% of boundary cases misclassified).
- Preference data was generated by annotators with unknown demographics.
- No personally-identifiable information screening was applied beyond what
  the source datasets perform.

## Evaluation Results

Evaluated against the base Qwen2.5-1.5B-Instruct and the SFT checkpoint.

| Comparison | Win Rate | 95% CI | n | Judge |
|---|---|---|---|---|
| DPO vs Base | **0.68** | [0.55, 0.79] | 150 | gpt-4o-mini |
| SFT vs Base | 0.58 | [0.45, 0.70] | 150 | gpt-4o-mini |
| DPO vs SFT | 0.57 | [0.44, 0.69] | 150 | gpt-4o-mini |

*Position-swap debiasing applied. Bootstrap CI over cases. Length-controlled
win rate: DPO vs Base 0.63 (controlling for DPO verbosity bias).*

**Deployment delta (GGUF vs safetensors):** –0.02 win-rate points.
Q4_K_M quantisation incurred negligible quality loss at 1.5B scale.

## Limitations

- **Scale:** 1.5B is a small model. Responses may be factually incorrect
  or incomplete on specialised topics.
- **Alignment tax:** DPO reduced general instruction-following ability by
  ~3 points on AlpacaEval (see regression gallery in the eval report).
- **Calibration:** The model sometimes states incorrect information with
  high confidence. Always verify technical claims independently.
- **Bias:** The model may reflect biases present in the training data,
  including biases toward particular programming paradigms, tools, or
  communities that are over-represented in developer-oriented datasets.
- **Context:** Responses are generated without access to external knowledge,
  documentation, or the user's specific codebase.

## Ethical Considerations

This model was fine-tuned for a benign developer-assistance use case.
We are not aware of significant misuse risks specific to this domain.
The base model (Qwen2.5-1.5B-Instruct) has Alibaba's safety guidelines
applied; our fine-tuning targeted domain style, not safety properties.
We make no claims about the model's safety for applications outside its
intended use.

## How to Use

```bash
# With Ollama (recommended):
ollama pull alignforge-dpo:v1
curl http://localhost:11434/api/generate \
  -d '{"model":"alignforge-dpo:v1","prompt":"How do I reverse a list in Python?","stream":false}'

# With the AlignForge API:
alignforge serve api --engine ollama
curl http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"dpo","messages":[{"role":"user","content":"How do I reverse a list?"}]}'
